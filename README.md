# 双色球智能分析系统

基于历史开奖数据进行多维统计分析与下期号码预测的 Python Web 应用。

## 📁 文件结构

```
├── ssq_analyzer.py      # 核心分析模块 - 统计分析与预测算法
├── ssq_updater.py       # 数据更新工具 - 自动获取最新开奖数据
├── ssq_web.py           # Web应用 - Flask服务端与前端页面
├── ssq_history.csv      # 历史数据文件 - 2024001~2026077 共385期
├── test_ssq_analyzer.py # 单元测试 - 31个测试用例覆盖全部功能
├── requirements.txt     # Python依赖列表
├── .gitignore           # Git忽略配置
└── README.md            # 项目说明文档
```

## ✨ 功能特性

### 1. 数据分析
- **频率分析**: 红球/蓝球出现次数统计与排名（显示具体次数）
- **遗漏值分析**: 号码连续未出现期数
- **冷热号识别**: 热号(高频)、冷号(低频)、温号(中频)分类
- **区间分布**: 一区(01-11)、二区(12-22)、三区(23-33)出号统计
- **奇偶分析**: 奇数/偶数号码分布规律
- **大小分析**: 大数(>16)/小数(≤16)分布规律

### 2. 号码预测
- **两组算法**: 算法A（频率统计均衡法）+ 算法B（多元回归预测法）
- **期数选择**: 支持近10期/30期/50期/全部数据预测
- **选中原因**: 每个号码标注选中条件（热号/冷号/高遗漏/区间回补等）
- **蓝球预测原因**: 显示蓝球预测原因和备选号码原因
- **特征分析**: 自动分析预测号码的奇偶/大小/区间分布
- **动态预测**: 通过滑动条调整算法参数，实时改变预测结果

### 3. 历史数据趋势图
- **可视化展示**: 红球1-33、蓝球1-16在同一行显示（表格布局）
- **搜索功能**: 支持按期号搜索
- **期数筛选**: 最近10期/30期/50期/全部数据
- **出现次数统计**: 柱状图显示各号码出现次数
- **左右布局**: 左侧历史数据(70%)，右侧数据分析(30%)

### 4. 数据更新
- **自动更新**: 从多个数据源自动获取最新开奖数据
- **增量更新**: 只添加本地缺失的数据
- **多源校验**: 同时从 17500.cn、gsflcp.com、ip138.com 获取，交叉验证

## 🚀 操作方法

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行Web应用

```bash
# 启动Web服务
python ssq_web.py

# 访问地址
http://127.0.0.1:5000
```

### 命令行工具

```bash
# 生成分析报告
python ssq_analyzer.py

# 先更新数据再生成报告
python ssq_analyzer.py --update

# 仅检查是否有新数据
python ssq_analyzer.py --check

# 强制全量更新(覆盖本地数据)
python ssq_analyzer.py --update --force
```

### 独立运行更新器

```bash
# 仅检查更新
python ssq_updater.py --check

# 自动更新
python ssq_updater.py

# 强制全量更新
python ssq_updater.py --force
```

### 运行测试

```bash
# 运行全部测试
python -m unittest test_ssq_analyzer

# 详细输出
python -m unittest test_ssq_analyzer -v
```

## 🎯 预测算法说明

### 算法A：频率统计均衡法

采用3热+2温+1冷的配比策略，结合区间、奇偶、大小均衡筛选。

**蓝球策略 - 多维智能预测（8种算法模型）**：
1. **频率热度模型**：热号偏好，近期高频号码（权重20分）
2. **遗漏回归模型**：中等遗漏号码回归倾向（遗漏≥8期：权重`omission×1.2`，遗漏≥25期：惩罚`-omission×0.3`）
3. **频率均衡模型**：频率接近平均值的号码更稳定（权重12分）
4. **质数分布模型**：质数(2,3,5,7,11,13)和合数的分布规律（权重10分）
5. **趋势追踪模型**：号码上升/下降趋势分析（权重6分）
6. **五行相生模型**：传统五行理论应用（权重8分）
7. **日期关联模型**：结合开奖日期特征（日/月/和）（权重6分）
8. **均值回归模型**：接近平均值的号码回归倾向（权重5分）

### 算法B：多元回归预测法

综合余数分类法、尾数关联法、区间回补法等多维指标交叉验证，与算法A形成互补。

**蓝球策略 - 多元回归预测（6种算法模型）**：
1. **冷号复苏模型**：适度冷号复苏概率（遗漏≤20期：权重15分，遗漏>20期：权重4分）
2. **对称分布模型**：首尾对称号码的关联性(如1和16, 2和15)（权重12分）
3. **振幅分析模型**：号码波动幅度的统计规律
4. **长期未出模型**：最近20期未出现的号码
5. **间隔重复模型**：隔期重复出现的规律
6. **差分预测模型**：号码差值的周期性规律

### 综合评分公式

```
Score(ball) = H(ball) + O(ball) + W(ball) + R(ball) + S(ball) + P(ball)
```

| 分项 | 说明 |
|------|------|
| H(ball) | 热号加分，频率越高加分越多 |
| O(ball) | 遗漏加分/惩罚，中等遗漏加分，超长期遗漏(>25期)惩罚 |
| W(ball) | 温号加分，频率处于中等水平 |
| R(ball) | 频率排名加分，排名越靠前分数越高 |
| S(ball) | 遗漏周期加分，超过阈值额外加分 |
| P(ball) | 多维特征加分（质数/合数、奇偶、大小、尾数、余数、对称等） |

### 超长期遗漏惩罚机制

为避免过度追冷，对遗漏超过25期的号码实施惩罚：

| 遗漏期数 | 算法A | 算法B |
|----------|-------|-------|
| 0-3期 | 无 | 无 |
| 3-5期 | +遗漏×0.5 | +遗漏×0.4 |
| 5-8期 | +遗漏×1.0 | +遗漏×0.8 |
| 8-15期 | +遗漏×1.2 | +遗漏×1.0 |
| 15-25期 | +遗漏×0.8 | +遗漏×0.6 |
| ≥25期 | -遗漏×0.3 | -遗漏×0.4 |
