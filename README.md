# 双色球智能分析系统

基于历史开奖数据进行多维统计分析与下期号码预测的 Python 工具。

## 📁 文件结构

```
├── ssq_analyzer.py      # 主程序 - 分析与预测核心模块
├── ssq_updater.py       # 数据更新工具 - 自动获取最新开奖数据
├── ssq_history.csv      # 历史数据文件 - 2026007~2026068 共62期
├── test_ssq_analyzer.py # 单元测试 - 31个测试用例覆盖全部功能
└── ssq_report_*.txt     # 分析报告(自动生成)
```

## ✨ 功能特性

### 1. 数据分析
- **频率分析**: 红球/蓝球出现次数统计与排名
- **遗漏值分析**: 号码连续未出现期数（遗漏越久理论概率越高）
- **冷热号识别**: 热号(高频)、冷号(低频)、温号(中频)分类
- **区间分布**: 一区(01-11)、二区(12-22)、三区(23-33)出号统计
- **奇偶分析**: 奇数/偶数号码分布规律
- **大小分析**: 大数(>16)/小数(≤16)分布规律
- **重复号分析**: 近5期重复出现的号码识别

### 2. 号码预测
- **红球预测**: 基于频率、遗漏值、冷热号等多维加权评分
- **蓝球预测**: 综合热号与遗漏值的蓝球推荐
- **特征分析**: 自动分析预测号码的奇偶/大小/区间分布

### 3. 数据更新
- **自动更新**: 从多个数据源自动获取最新开奖数据
- **增量更新**: 只添加本地缺失的数据，不覆盖已有数据
- **多源校验**: 同时从 17500.cn、gsflcp.com、ip138.com 获取，交叉验证

### 4. 报告生成
- **详细报告**: 包含10个分析章节的完整报告
- **自动保存**: 报告自动保存为时间戳命名的文本文件

## 🚀 操作方法

### 安装依赖

```bash
# 安装网络请求库(数据更新功能需要)
pip install requests
```

### 基本使用

```bash
# 生成分析报告
python ssq_analyzer.py

# 指定数据文件
python ssq_analyzer.py --file ssq_history.csv
```

### 数据更新

```bash
# 先更新数据再生成报告
python ssq_analyzer.py --update

# 仅检查是否有新数据
python ssq_analyzer.py --check

# 强制全量更新(覆盖本地数据)
python ssq_analyzer.py --update --force
```

### 独立运行更新器

```bash
# 仅检查更新
python ssq_updater.py --check

# 自动更新
python ssq_updater.py

# 强制全量更新
python ssq_updater.py --force
```

### 运行测试

```bash
# 运行全部测试
python -m unittest test_ssq_analyzer

# 详细输出
python -m unittest test_ssq_analyzer -v
```

## 🎯 预测算法说明

### 一、红球预测公式

预测基于**多维加权评分模型**，对候选号码进行综合评分，取最高分的6个号码。

#### 1. 候选号码筛选

```
候选集合 = 热号前4名 ∪ 遗漏前3名 ∪ 温号前3名 ∪ 近期重复前2名
```

#### 2. 综合评分公式

```
Score(ball) = H(ball) + O(ball) + W(ball) + R(ball) + S(ball)
```

其中：

| 分项 | 公式 | 说明 |
|------|------|------|
| **H(ball)** - 热号加分 | `30, if ball ∈ 热号前5名`<br>`15, if ball ∈ 热号前8名`<br>`0, otherwise` | 频率越高加分越多 |
| **O(ball)** - 遗漏加分 | `25, if ball ∈ 遗漏前3名`<br>`10, if ball ∈ 遗漏前6名`<br>`0, otherwise` | 遗漏越久加分越多 |
| **W(ball)** - 温号加分 | `15, if ball ∈ 温号`<br>`0, otherwise` | 频率处于中等水平 |
| **R(ball)** - 频率排名加分 | `max(0, 20 - freq_rank × 0.5)` | 排名越靠前分数越高，最高20分 |
| **S(ball)** - 遗漏周期加分 | `omission × 1.5, if omission ≥ 8`<br>`omission, if omission ≥ 5`<br>`0, otherwise` | 遗漏超过5期额外加分 |

#### 3. 符号定义

- `freq_rank`: 号码频率排名（0=最高频，32=最低频）
- `omission`: 号码当前遗漏期数（连续未出现的期数）
- `热号`: 出现频率最高的前8个号码
- `冷号`: 出现频率最低的前5个号码
- `温号`: 频率在平均频率±20%范围内的号码

### 二、蓝球预测公式

```
Score(ball) = H(ball) + O(ball) + R(ball) + S(ball)
```

其中：

| 分项 | 公式 | 说明 |
|------|------|------|
| **H(ball)** - 热号加分 | `30, if ball ∈ 热号前3名`<br>`0, otherwise` | |
| **O(ball)** - 遗漏加分 | `25, if ball ∈ 遗漏前3名`<br>`0, otherwise` | |
| **R(ball)** - 频率排名加分 | `max(0, 20 - freq_rank)` | 最高20分 |
| **S(ball)** - 遗漏周期加分 | `omission × 2, if omission ≥ 6`<br>`omission, if omission ≥ 3`<br>`0, otherwise` | |

### 三、号码选择流程

```
1. 筛选候选号码（红球约12-15个，蓝球全部16个）
2. 计算每个号码的综合评分
3. 按评分降序排序
4. 取前6个红球、前1个蓝球作为预测结果
5. 校验奇偶/大小分布是否符合历史众数（软约束）
6. 对号码进行升序排列输出
```

### 四、权重参数表

| 参数 | 红球值 | 蓝球值 | 说明 |
|------|--------|--------|------|
| 热号阈值 | 5/8 | 3 | 前N名为高分热号 |
| 热号高分 | 30分 | 30分 | |
| 热号低分 | 15分 | - | |
| 遗漏阈值 | 3/6 | 3 | 前N名为高遗漏 |
| 遗漏高分 | 25分 | 25分 | |
| 遗漏低分 | 10分 | - | |
| 温号加分 | 15分 | - | |
| 排名基础分 | 20分 | 20分 | |
| 排名衰减系数 | 0.5 | 1.0 | 每降1名扣N分 |
| 高遗漏倍率 | 1.5× | 2× | 遗漏≥8/6期时 |
| 中遗漏倍率 | 1.0× | 1.0× | 遗漏≥5/3期时 |

### 五、冷热号判定标准

```
平均频率 = 总出现次数 ÷ 33（红球）或 ÷ 16（蓝球）

热号: 频率 > 平均频率 × 1.2
温号: 平均频率 × 0.8 ≤ 频率 ≤ 平均频率 × 1.2
冷号: 频率 < 平均频率 × 0.8
```
